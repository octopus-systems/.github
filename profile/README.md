### What we build

Most growing businesses don't need more software. They need the software they already have to work as one system. We build the layer that connects it: clear workflows, the right data in view, and AI that drafts the routine work for a person to approve.

| System | What it covers |
| --- | --- |
| **Business OS** | Tasks, approvals and daily operations, with a clear owner for every step |
| **Commerce OS** | Sales, costs and product margin in one view, including Shopify stores |
| **Support OS** | Customer conversations with order context and AI-drafted replies, reviewed before sending |
| **Trade OS** | Supplier quotes, buying decisions and unit margin side by side |
| **Custom development** | Client portals, internal tools, web apps, SaaS products, APIs and integrations |

### How we build

- **Problem first.** We agree the goal before choosing tools.
- **Start small.** One process, one pilot, then expand when it proves its value.
- **People in control.** Refunds, discounts and customer replies wait for human approval. Every action has an owner and a log.
- **Connect, don't replace.** We work on top of the tools a team already uses, and we verify every integration before we promise it.
- **Your data stays yours.** Access is limited to what a project needs, agreed in writing before work starts.
